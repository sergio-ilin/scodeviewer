# ⚡ sCodeViewer

> **Сверхбыстрый, нативный и минималистичный ревьювер кода и трекер изменений**
> Написан на **Go**, скомпилирован в единый легковесный бинарник без внешних зависимостей.

---

## 🚀 Особенности и преимущества

- **Нативная скорость и компактность**:
  - Написан на Go, без Electron и тяжелых фреймворков.
  - Потребляет минимум ресурсов (~15–40 МБ ОЗУ) и стартует за доли секунды.
  - Все статические файлы (HTML/CSS/JS) встроены прямо в исполняемый файл (`//go:embed`).
  - Размер готового бинарника всего **~7 МБ**.

- **Мержи, коммиты и код-ревью**:
  - Быстрое переключение веток репозитория.
  - Отображение авторов, дат, родительских коммитов (для мерж-коммитов).
  - Специфическое выделение мержей (`Merge Commit`) со ссылками на родительские хэши.
  - Полнофункциональный просмотр диффов: **Unified** (единый) и **Split** (бок о бок).
  - Подсветка добавленных и удаленных строк, счетчик файлов и строк `+` / `-`.

- **Раздел «Апдейты» (Временные срезы и трекинг ИИ)**:
  - Срезы за периоды: *1 час*, *24 часа*, *Сегодня*, *3 дня*, *7 дней*, *30 дней*, *Все время* или *Кастомный интервал*.
  - Автоматическое выявление изменений от **ИИ** (Claude, Cursor, Copilot, Aider, Devin, Windsurf, ChatGPT и др.).
  - Разделение активности: **🤖 Только ИИ** vs **👤 Разработчики-люди** с расчетом процентного соотношения.
  - Сводка по участникам (коммиты, мержи, объем написанного и удаленного кода).
  - Хронологическая лента событий с возможностью в 1 клик открыть дифф любого изменения.

- **Темы оформления (Минималистичный дизайн)**:
  - Автоматическое определение системной темы Windows/macOS/Linux (`prefers-color-scheme`).
  - Мгновенный переключатель тем в один клик: **Авто** 🌓 / **Тёмная** 🌙 / **Светлая** ☀️.
  - Лаконичный, строгий интерфейс, сфокусированный на коде.

- **Мультипроектность**:
  - Добавление любых папок с Git-репозиториями на диске.
  - Быстрое переключение между добавленными проектами.
  - Автоматическое запоминание последних открытых репозиториев в конфигурации пользователя.

## 🛠 Запуск и использование

### 1. Быстрый запуск
В консоли перейдите в папку проекта и запустите:
```powershell
.\scodeviewer.exe
```
Программа автоматически определит репозиторий в текущей папке, запустит легковесный сервер и откроет окно приложения.

### 2. Аргументы командной строки
- `-path <путь>`: открыть конкретную папку с репозиторием (например, `.\scodeviewer.exe -path "C:\my-project"`).
- `-port <порт>`: задать порт HTTP (по умолчанию: `52480`).
- `-open=false`: запустить сервер без автоматического открытия окна браузера.
- `-app=false`: открывать в стандартном окне браузера вместо изолированного окна приложения.

## 🔨 Сборка из исходников

Для компиляции требуется только установленный Go (1.20+):

```bash
go build -ldflags="-s -w" -o scodeviewer.exe .
```
Флаги `-s -w` отсекают отладочную информацию для достижения минимального размера файла (~7 МБ).
